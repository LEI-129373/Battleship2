# Tarefa 2B — Checkstyle (129373)

## Regra escolhida

- **Categoria:** Nomes de métodos Java
- **Regra Checkstyle:** `MethodName`
- **Ficheiro de configuração:** `checkstyle-129373.xml`
- **Workflow:** `.github/workflows/checkstyle-129373.yaml`

A regra exige que os nomes dos métodos comecem por uma letra minúscula e respeitem o padrão `^[a-z][a-zA-Z0-9]*$`.

## Demonstração da violação

Foi criado o método `MetodoComNomeErrado()` no ficheiro `src/main/java/battleship/CheckstyleTest129373.java`.

O Checkstyle detetou a violação na linha 5, porque o nome começava por uma letra maiúscula.

- **Execução vermelha:** https://github.com/LEI-129373/Battleship2/actions/runs/42412508565
- **Execução verde após correção:** https://github.com/LEI-129373/Battleship2/actions/runs/42413063125
- **Pull Request:** https://github.com/LEI-129373/Battleship2/pull/16/

A correção consistiu em alterar `MetodoComNomeErrado()` para `metodoComNomeErrado()`.

## Proteção da branch main

Foi configurado um ruleset para exigir que o check `Checkstyle MethodName 129373` passe antes de permitir o merge na branch `main`.

## Limitações da regra

A regra `MethodName` verifica apenas se os nomes dos métodos respeitam o padrão definido, não avaliando se são claros ou descritivos. Por exemplo, um método chamado `abc()` passa na verificação, apesar de o nome não explicar a sua finalidade. Assim, o Checkstyle ajuda a garantir consistência na nomenclatura, mas não substitui a revisão humana do código.
